# Week 1 data-preparation outputs

This folder contains quality summaries and a record of the corrected cohort-preparation decisions. The versioned cohort table is in `data/processed/student_risk_at_day_63.csv`.

Run the scripts in `scripts/` after placing the seven OULAD source CSV files in `data/raw/` to regenerate the reports. Source data and audit files containing student IDs are not committed.
